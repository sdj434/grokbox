流式输出（打字机效果）
完全离线免费，没有次数限制。
先在手机或同 WiFi 的电脑上起一个 OpenAI 兼容服务，再填地址：
· Termux 里 llama.cpp：llama-server -m model.gguf -c 4096 --host 0.0.0.0 --port 8080
· Ollama：ollama serve，地址 http://127.0.0.1:11434/v1
· 电脑上跑：把 127.0.0.1 换成电脑的局域网 IP，手机同 WiFi
· llama.cpp / Ollama 不校验 key，留空即可
流式输出

· 登录 X / Google 账号后，对话记录存在官方云端，换设备也在；
